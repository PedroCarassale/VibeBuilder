# Skills usadas en VibeBuilder

Esta carpeta agrupa las skills que se usaron o quedaron asociadas al trabajo del proyecto VibeBuilder.

## Contenido

| Skill | Carpeta | Uso en el proyecto |
| --- | --- | --- |
| VibeBuilder Compose UI Style | `vibebuilder-compose-ui-style/` | Skill propia del repo para mantener consistencia visual en pantallas Android con Jetpack Compose. |
| PDF | `pdf/` | Skill usada para crear y verificar documentos PDF, incluido `output/pdf/doc_tecnica_e2.pdf`. |
| sp-vercel | `sp-vercel/` | Guia de despliegue y manejo de Vercel asociada al proyecto. Se relaciona con `docs/deploy-vercel.md` y el backend en Vercel. |

## Notas

- `vibebuilder-compose-ui-style/` tambien existe en `skills/` porque es una skill propia del proyecto.
- Las demas skills fueron copiadas desde el entorno local del agente para dejar una referencia versionable dentro del repositorio.
- Esta carpeta no reemplaza la configuracion real de Codex ni instala skills automaticamente; funciona como archivo de referencia del proyecto.
